# Password Generator (CLI)

A command-line application built with Python for generating secure, customizable passwords.

## Features

- **Customizable character sets:** Choose whether to include lowercase letters, uppercase letters, digits, and punctuation marks.
- **Security enforcement:** Enforces a minimum length of 8 characters.
- **Interactive prompt:** Simple text-based workflow to configure and generate passwords on demand.

## Technologies

- Python 3
- Standard libraries: `random`, `string`

## Getting Started

1. Ensure Python 3 is installed on your system.
2. Download or clone the project files.
3. Run the script from your terminal or command line:
   ```bash
   python generateur_console.py
